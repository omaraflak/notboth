The final computer, three chips: `CPU`, `RAM`, `ROM`.

> Use the built-in `RAM` and `ROM`.

- The program to execute lives in the `ROM`.
- The `reset` bit will set the `PC` counter inside the `CPU` to zero. It boots the machine.
- The CPU outputs that initial `pc` which it feeds into the `ROM` to get the value of the next instruction.
- The instruction fetched from the `ROM` simply goes back into the `CPU` to be executed.
- The `RAM` is wired to the `CPU`'s `writeM`/`addressM`/`outM` fields.

> To run your machine you will need to set some initial values into the ROM, but also inspect the RAM while the machine is running. Just select the built-in ROM or RAM chips on your circuit in the UI and those options appear on the right panel.

> The clock's half period, must be longer than the deepest path in your computer. Setting the period to 512 should be safe.

The routing counterpart.

When you build RAM you will hand it an address and expect exactly one cell to react. This chip is what helps you build that.

::: answer
**DMux4Way**

```circuit DMux4Way
in  in
in  sel[2]
out a
out b
out c
out d

hi : DMux(in = in, sel = sel[1])
lo1 : DMux(in = hi.a, sel = sel[0])
lo2 : DMux(in = hi.b, sel = sel[0])

a = lo1.a
b = lo1.b
c = lo2.a
d = lo2.b
```

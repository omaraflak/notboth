A program that turns readable mnemonics into the bits you just encoded by
hand. Write it in whatever language you like; it runs on your own computer,
not on the one you built.

Two features earn their keep immediately: **symbolic names** for instructions,
and **labels** for addresses, so that a jump target is `@loop` and not the
number 47 — a number that changes the moment you insert a line. Everything
else is optional.

This is also the first opportunity to write a real test: assemble the program
from 5.01 and check you get the same bits you produced by hand.

We now have an assembler, this is a huge step! We could stop here and program using assembler, in fact this is what people used to do at some point in time. But how do we go from this, to a more modern programming language?

First, we need to see how to build some usual programming constructs we know of: `if`-conditions, `while`-loops, and functions.

## Conditions

A condition is nothing else but a jump! Think about it:

```
if (condition) {
    // do this
}
```

This translates to evaluting the condition, and jumping **over** the `if` body if the condition is `false`.

>We don't need to support booleans directly, we do this with numbers, subtraction, and comparison:
>- `a==b` is `a-b==0`
>- `a<b` is `a-b<0`
>- `a>b` is `a-b>0`
>- etc.

```
// evaluate condition and put result in D
// ...

// jump over the body if the condition is false:
@END
D;JLE

// if-condition body here

(END)
```

## Loops

Similarily, a `while`-loop is also a jump:

```
(LOOP)

// while-loop body here

// evaluate condition and result in D
// ...

// jump back to the beginning of the loop if the condition is true
@LOOP
D;JGE
```

## Functions

Functions are just addresses in the code where we jump to, they perform computation, optionally write a result back into some register, then jump back to the caller:

```
// set R0 to END_CALL (return address)
@END_CALL
D=A
@R0
M=D

// R1=7
@7
D=A
@R1
M=D

// call MY_FUNCTION
@MY_FUNCTION
0;JMP
(END_CALL)

// any code here...

// a function that does R2=R1+10, and jumps back to R0
(MY_FUNCTION)
@10
D=A

@R1
D=M+D

@R2
M=D

@R0
0;JMP
```

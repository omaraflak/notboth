title: DMux
sig: DMux(in, sel) → a, b

DMUX gate (*demultiplexer*) is the mirror image of MUX. It writes its input to **one of** several outputs based on a selector.

```truth
sel | in | >a | >b
0 | 0 | 0 | 0
0 | 1 | 1 | 0
1 | 0 | 0 | 0
1 | 1 | 0 | 1
```

While a MUX *gathers*, a DMUX *routes*. You will need it the moment you build memory: storing a value at an address means delivering a write signal to exactly one cell out of many. Addressing is demultiplexing.

::: answer
```circuit DMux
in  in
in  sel
out a
out b

and1 : And(a = sel, b = in)
and2 : And(a = in, b = not1.out)
not1 : Not(in = sel)

a = and2.out
b = and1.out
```
:::

num: 1.06
title: DMux
sig: DMux(in, sel) → a, b
needs: 1.01, 1.02
---

DMUX gate (*demultiplexer*) is the mirror image of MUX. It writes its input to **one of** several outputs based on a selector.

```truth
sel | in | >a | >b
0 | 0 | 0 | 0
0 | 1 | 1 | 0
1 | 0 | 0 | 0
1 | 1 | 0 | 1
```

Where a mux *gathers*, a demux *routes*. You will need it the moment you build memory: storing a value at an address means delivering a write signal to exactly one cell out of many and to none of the others. Addressing is demultiplexing.

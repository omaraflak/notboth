Decide what lives at which addresses, and write that down too. Some region is
working memory. If you want a screen or a keyboard, they get addresses as
well.

That last point is worth dwelling on. If a screen is simply a range of memory
addresses whose contents happen to be displayed, then drawing a pixel is
*storing a number*, and you need no new instructions, no new hardware path,
and no concept of input or output at all. It is one of the tidiest economies
in the design, and it costs nothing but a decision made now.

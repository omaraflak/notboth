Right now, you can program this machine in binary. It's doable, but really tedious. The immediate next step is not a fully fleched out programming language, but it's just about building strings that map to the binary (1:1), like labeling system. This is **Assembly**.

Here are a few samples of the result we want.

## instruction[15]=0

Remember that when the most significant bit of the instruction `0`, we load the next 15 bits into register `A`. We will use `@` to represent this instruction:

```
@42
```

This loads number `42` into register `A`.

## instruction[15]=1

When the most significant bit of the instruction `1`, the ALU performs a computation between `D` and one of `A` or `M=RAM[A]`, then optionally saves the result into any of `A`, `D`, and `M`, then optionally jumps the PC counter to the address in `A` based on the result on the result of the computation (`positive`, `negative`, or `zero`, or any combination of those). Therefore, the full syntax will be:

```
result=compute;jmp
```

With `result=` and `;jmp` being optional, i.e. destination bits and jump bits set to `0`.

- `result=` can be one of: `A=`, `D=`, `M=`, `AD=`, `AM=`, `DM=`, `ADM=`.
- `compute` can be one of the computations from [2.06](manual.html#s206) where `x=D` and `y=D` or `y=M`.
- `jmp` can be of one of: `JGT`, `JGE`, `JLT`, `JLE`, `JEQ`, `JNE`, `JMP` (`>0`, `>=0`, `<0`, `<=0`, `==0`, `!=0`, `1`).

Finally, we will support two additional features to make our life easier:

- ***labels***: placing a label in the middle of the code, e.g. `(MY_LABEL)`, like an anchor we can jump to. The assembler will automatically count the instructions and replace jumps to labels with the proper addresses.

- ***variables***: instead of allocating memory in the RAM by numbers (addresses) we can use strings, e.g. `@i`, and the assembler will automatically assign an address of the RAM to that string and replace the variable in the code by its address. If the assembler sees another variable, e.g. `@j`, it will simply assign it to the next available address.

Examples:

## Load a value in the RAM

```
// A=10
@10
// D=A=10
D=A

// A=5
@5
// RAM[5]=D=10
M=D
```

> `M` points to `RAM[A]`, whatever `A` is. So you need to load `A` with the address you want when using memory, in this case `5`.

## Arithmetic on registers

```
// D=10
@10
D=A

// A=5
@5

// D=15
D=D+A
```

## Labels & Jumps

A jump instruction always jumps to the address in `A`:

```
// A=MY_LABEL (address of MY_LABEL)
@MY_LABEL

// compute 0 (compute is not optional, the ALU always goes through a computation), then jumps unconditionnaly to A=MY_LABEL
0;JMP

// RAM[1]=1 <-- this will be skipped (jumped over)
@1
M=A

(MY_LABEL)
```

## Conditional jumps

```
// D=10
@10
D=A

// Jump to address `100` if D>0
@100
D;JGT
```

## Variables

Variables are just labels to addresses that are resolved when the code is assembled:

```
// RAM[i]=5
@i
M=5
```

So here, `i` might take for example the address `17` for the rest of the execution; and you just refer to it as `i`, instead of `17`.

## Try it

Type assembly on the left and the words for the ROM appear on the right. Select the ROM chip in your circuit, open the program editor in the right panel, and paste them in.

This assembly code shows the code of the while loop in section [4.07](/manual.html#s407).

```assembler
// RAM[i]=0
@i
M=0

(LOOP)
// RAM[i]=i
@i
D=M
A=M
M=D

// i++
@i
M=M+1

// D=10-i
@10
D=A
@i
D=D-M

// if (D>0) goto LOOP
@LOOP
D;JGT

(END)
@END
0;JMP
```

## Assembler code in Python

Here's a python implementation that will take assembly code and produce the corresponding binary code for our machine. Try to implement yourself, and come back for the result!

```python collapse
# Assembler implemented in Python.
import os
import sys

COMP_TABLE = {
    # a=0 (Register A)
    "0":   "0101010",
    "1":   "0111111",
    "-1":  "0111010",
    "D":   "0001100",
    "A":   "0110000",
    "!D":  "0001101",
    "!A":  "0110001",
    "-D":  "0001111",
    "-A":  "0110011",
    "D+1": "0011111",
    "A+1": "0110111",
    "D-1": "0001110",
    "A-1": "0110010",
    "D+A": "0000010",
    "D-A": "0010011",
    "A-D": "0000111",
    "D&A": "0000000",
    "D|A": "0010101",
    # a=1 (Memory M[A])
    "M":   "1110000",
    "!M":  "1110001",
    "-M":  "1110011",
    "M+1": "1110111",
    "M-1": "1110010",
    "D+M": "1000010",
    "D-M": "1010011",
    "M-D": "1000111",
    "D&M": "1000000",
    "D|M": "1010101",
}

DEST_TABLE = {
    None:  "000",
    "":    "000",
    "M":   "001",
    "D":   "010",
    "DM":  "011",
    "A":   "100",
    "AM":  "101",
    "AD":  "110",
    "ADM": "111",
}

JUMP_TABLE = {
    None:  "000",
    "":    "000",
    "JGT": "001",
    "JEQ": "010",
    "JGE": "011",
    "JLT": "100",
    "JNE": "101",
    "JLE": "110",
    "JMP": "111",
}


def assemble_line(line: str) -> bytes:
    # Strip comments and surrounding whitespace
    line = line.split("//")[0].strip()
    if not line:
        return b""

    # A-instruction: @value
    if line.startswith("@"):
        val_str = line[1:].strip()
        val = int(val_str)
        if not (0 <= val <= 0x7FFF):
            raise ValueError(
                f"A-instruction value out of range (0-32767): {val}")
        return val.to_bytes(2, byteorder="big")

    # C-instruction: [dest=]comp[;jump]
    dest, comp, jump = "", "", ""
    rest = line

    if "=" in rest:
        dest, rest = rest.split("=", 1)
        dest = dest.strip()

    if ";" in rest:
        comp, jump = rest.split(";", 1)
        comp = comp.strip()
        jump = jump.strip().upper()
    else:
        comp = rest.strip()

    if comp not in COMP_TABLE:
        raise ValueError(
            f"Unknown computation in C-instruction: '{comp}' from '{line}'")
    if dest not in DEST_TABLE:
        raise ValueError(
            f"Unknown dest in C-instruction: '{dest}' from '{line}'")
    if jump not in JUMP_TABLE:
        raise ValueError(
            f"Unknown jump in C-instruction: '{jump}' from '{line}'")

    comp_bits = COMP_TABLE[comp]
    dest_bits = DEST_TABLE[dest]
    jump_bits = JUMP_TABLE[jump]

    bit_string = f"111{comp_bits}{dest_bits}{jump_bits}"
    return int(bit_string, 2).to_bytes(2, byteorder="big")


def assemble(code: str) -> list[bytes]:
    """
    Two-pass assembler supporting labels (LABEL) and variables (@var).
    """
    symbol_table = {
        **{f"R{i}": i for i in range(16)},
        "SCREEN": 22768
    }

    # First pass: clean comments and extract label definitions (LABEL)
    lines: list[str] = []
    rom_address = 0

    for raw_line in code.splitlines():
        line = raw_line.split("//")[0].strip()
        if not line:
            continue

        if line.startswith("(") and line.endswith(")"):
            label = line[1:-1].strip()
            if not label:
                raise ValueError(f"Empty label declaration: '{line}'")
            symbol_table[label] = rom_address
        else:
            lines.append(line)
            rom_address += 1

    # Second pass: resolve variables (@symbol) and generate binary instructions
    next_var_address = 16
    instructions: list[bytes] = []

    for line in lines:
        if line.startswith("@"):
            symbol = line[1:].strip()
            if symbol.isdigit():
                val = int(symbol)
            else:
                if symbol not in symbol_table:
                    symbol_table[symbol] = next_var_address
                    next_var_address += 1
                val = symbol_table[symbol]
            line = f"@{val}"

        ins = assemble_line(line)
        if ins:
            instructions.append(ins)

    return instructions


if __name__ == "__main__":
    filename, output = sys.argv[1:]

    if os.path.exists(filename):
        with open(filename, "r") as f:
            source = f.read()

    program = assemble(source)
    string = "\n".join(["0x" + ins.hex() for ins in program])
    with open(output, 'w') as out:
        out.write(string)

    print(f'Wrote {len(program)} bytes to program.bin')
```

Your CPU needs somewhere to hold values it is working on. Two registers is
enough, and each has a distinct character worth respecting.

One holds *data* — a number being worked on. The other does double duty: it
holds either a value, or an *address* — which memory location to read or
write, or which instruction to jump to. That double duty is what lets a
machine with almost no instructions still reach any part of memory. To use a
memory location, you first put its address in that register, then operate.

Sixteen bits of storage each, a load signal each. You already built these.

You can now try your first program on this computer! Click on the ROM chip, then on the program editor button in the right panel, and paste the following code:

```
0x0010
0xea88
0x0010
0xfc10
0xfc20
0xe308
0x0010
0xfdc8
0x000a
0xec10
0x0010
0xf4d0
0x0002
0xe301
0x000e
0xea87
```

Save the content, run the circuit, set the `reset` input to `1`, click on the reset button in the top bar to set all RAM values to `0`, finally toggle the `reset` input to `0` to start the machine.

If you click on the RAM chip, you will see its content in the right panel. If your machine is built properly, you should see the first 10 memory addresses filled with numbers from `0` to `9`. Indeed, the program above is just a loop:

```
i=0
while (i<10) {
    RAM[i]=i
    i++
}
```

However, it's clearly unreadable code. Nonetheless it'd be good for you to build simple programs, such as assigning a single value to the RAM.

In the next part, we'll build an Assembly language on top of the machine we have so we can easily program it.

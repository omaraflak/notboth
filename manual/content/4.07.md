---
num: 4.07
title: Talking to the world
sig: no new chip — a region of RAM that something else is watching
needs: 4.02
---

Optional, and worth it. If you reserved addresses for a screen and a keyboard
back in 4.02, wire them up now — a region of memory whose contents are
displayed, and a location that holds whichever key is currently down.

Notice that the CPU needs no changes whatsoever. It has no idea a screen
exists. It stores a number at an address, exactly as it always does, and
something else is watching.

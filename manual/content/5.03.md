Functions need somewhere to keep their local variables and their return
address, and it must nest — a function can call a function that calls a
function. A stack is the structure that does this, and it is not hardware: it
is a region of RAM plus a register holding a pointer to the top of it, plus a
set of rules everyone agrees to follow.

Design the rules deliberately and write them down: who pushes the arguments,
who saves what, where the return value lives, who cleans up. This is the
bridge between a machine that runs instructions and a machine that runs
*programs*, and almost every hard bug in the rest of the project will be a
violation of these rules.

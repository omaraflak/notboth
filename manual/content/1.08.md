A gate to output `1` when *any* one of the input bits is `1`.

This is how your machine answers "is this number zero?", which is the basis of conditional branching.

::: answer
```circuit Or16Way
in  in[16]
out out

or1 : Or(a = in[0], b = in[1])
or2 : Or(a = or1.out, b = in[2])
or3 : Or(a = or2.out, b = in[3])
or4 : Or(a = or3.out, b = in[4])
or5 : Or(a = or4.out, b = in[5])
or6 : Or(a = or5.out, b = in[6])
or7 : Or(a = or6.out, b = in[7])
or8 : Or(a = or7.out, b = in[8])
or9 : Or(a = or8.out, b = in[9])
or10 : Or(a = or9.out, b = in[10])
or11 : Or(a = or10.out, b = in[11])
or12 : Or(a = or11.out, b = in[12])
or13 : Or(a = or12.out, b = in[13])
or14 : Or(a = or13.out, b = in[14])
or15 : Or(a = or14.out, b = in[15])

out = or15.out
```
:::

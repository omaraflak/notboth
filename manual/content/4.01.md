Our machine will need only three registers to function properly:

* `A` — an address register ([3.06](/manual.html#s306)). This register can hold an address pointing to the RAM *or* a data value directly. The interpretation of `A`'s content will depend on the instruction using it.
* `D` — a data register ([3.06](/manual.html#s306)). This register holds only data.
* `PC` — a program counter ([3.08](/manual.html#s308)). This register holds the address of the instruction to execute next.

Now assemble the CPU. This is the largest chip you will draw. It can look like
too much at first; it helps that everything in it is a part you have already
built and tested.

The structure is a loop. The ALU takes two inputs — one always from the data
register, the other selected between the address register and a value fetched
from memory. Its output goes back to the registers and out to memory. Which of
those actually happen is decided by the control bits from 4.04. Every one of
those choices is a mux; every mux is stage 1.05.

Work in the order the signal flows and test as you go: get the ALU fed
correctly first, then get its output stored correctly, then worry about jumps.

::: watch
The single most common bug here is a value being read in the same tick it is
written. Sketch on paper what is stable when. This is exactly the discipline
the flip-flop bought you in 3.04 — use it.
:::

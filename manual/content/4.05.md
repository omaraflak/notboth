At last, the CPU! Its circuit holds registers `A` and `D`, the `ALU`, `Decode`, `Jump`, and the
program counter `PC` chips.

Its job is to take an instruction, decode it, execute it, read/write to registers `A`/`D` and/or RAM, and increment or jump the program counter `PC`.

The inputs are:

- `instruction` — the 16-bit instruction to execute.
- `inM` — the value of a register in the RAM (fetched at `addressM`, outputted at the previous turn).
- `reset` — to reset the program counter `PC`.
- `clk` — the clock running the whole machine.

The outputs are:

- `outM`, `writeM`, `addressM` — The value `outM` is to be written to the RAM at `addressM` if `writeM=1`.
- `pc` — the value of the `PC` register after being incremented or loaded, i.e. the address of the next instruction.

::: watch
Remember to explicitly handle the case where `op=0`, i.e. load register `A` with the 15 bit value of the instruction.
:::

```circuit CPU collapse
in  instruction[16]
in  inM[16]
in  reset
in  clk
out outM[16]
out writeM
out addressM[16]
out pc[16]

jump : Jump(zr = alu.zr, ng = alu.ng, j1 = decode1.j1, j2 = decode1.j2, j3 = decode1.j3)
decode1 : Decode(instruction = instruction)
pc2 : PC(in = register_A.out, load = jump.load, inc = const1.out, reset = reset, clock = clk)
register_D : Register(in = alu.out, load = decode1.loadD, clock = clk)
register_A : Register(in = mux16_2.out, load = decode1.loadA, clock = clk)
alu : ALU(a = register_D.out, b = mux16_1.out, za = decode1.za, na = decode1.na, zb = decode1.zb, nb = decode1.nb, f = decode1.f, no = decode1.no)
mux16_1 : Mux16(a = register_A.out, b = inM, sel = decode1.isAddr)
const1 : Const(width = 1, value = 1)
mux16_2 : Mux16(b = alu.out, sel = instruction[15])

mux16_2.a[14..0] = instruction[14..0]

outM = alu.out
writeM = decode1.writeM
addressM = register_A.out
pc = pc2.out
```

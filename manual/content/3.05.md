num: 3.05
title: Bit
sig: Bit(in, load, clk) → out
needs: 1.05, 3.04
---

A flip-flop copies the data, whatever it is, every single clock tick. So if `d` doesn't happen to hold what you want to write during a rising edge of the clock, you are in a bad position because it is written to `q` anyways!

What you want is storage that *keeps* or *discards* its value only if you ask it to. This is the `Bit`!

- `in` — the value to store.
- `load` — `1` will write `in` to `out` at the next rising edge of `clk`, while `0` should hold the value of `out`.
- `clk` — same as in [3.04](/manual.html#s304).
- `out` — same as in [3.04](/manual.html#s304).

**So on each rising edge, store either the new input or the value already held**.

```wave
!Timing diagram for a one-bit register
clk      1100110011001100
in       0111100001100111
load     0011000001111000
>out     0000111111110000
@4 load
@8 hold
@12 load
```

The middle edge is the one to look at. `in` has gone low and the clock has ticked, but because `load` is also low, `out` remains unchanged.

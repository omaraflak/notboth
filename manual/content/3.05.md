---
num: 3.05
title: Bit
sig: Bit(in, load, clk) → out
needs: 3.04, 1.05
---

A flip-flop takes whatever arrives, every single tick. What you want is
storage that *keeps* its value until told otherwise.

- **in** — the value to store.
- **load** — 1 takes `in` at the next edge, 0 keeps what is already there.
- **clk** and **out** — as in 3.04.

So on each edge, store either the new input or the value already held.
Choosing between two values with a control bit is a multiplexer, and the
second value comes from the flip-flop’s own output: a one-bit register is a
flip-flop with a mux in its feedback path. That is where stage 1.05 pays for
itself.

```wave
!Timing diagram for a one-bit register
clk      1100110011001100
in       0111100001100111
load     0011000001111000
>out     0000111111110000
@4 load
@8 hold
@12 load
```

The middle edge is the one to look at. `in` has gone low and the clock has
ticked, either of which would have moved a bare flip-flop, and `out` does not
move — because `load` was low and the mux was feeding the flip-flop its own
output. Storage is the flip-flop plus somewhere for the old value to go round
again.

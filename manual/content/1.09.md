Currently, `Mux16` allows you to choose between two words. This is not always enough, so build the four-way version, and then eight-way version out of it.

* four-way: 2 selector bits and four candidate words.
* eight-way: 3 selector bits and eight candidate words.

> Remember to reuse existing components.

::: answer
**Mux4Way16**

```circuit Mux4Way16
in  a[16]
in  b[16]
in  c[16]
in  d[16]
in  sel[2]
out out[16]

mux16_1 : Mux16(a = a, b = c, sel = sel[1])
mux16_2 : Mux16(a = b, b = d, sel = sel[1])
mux16_3 : Mux16(a = mux16_1.out, b = mux16_2.out, sel = sel[0])

out = mux16_3.out
```

**Mux8Way16**

```circuit Mux8Way16
in  a[16]
in  b[16]
in  c[16]
in  d[16]
in  e[16]
in  f[16]
in  g[16]
in  h[16]
in  sel[3]
out out[16]

mux4Way16_1 : Mux4Way16(a = a, b = b, c = c, d = d, sel = sel[1..0])
mux4Way16_2 : Mux4Way16(a = e, b = f, c = g, d = h, sel = sel[1..0])
mux16_1 : Mux16(a = mux4Way16_1.out, b = mux4Way16_2.out, sel = sel[2])

out = mux16_1.out
```
:::

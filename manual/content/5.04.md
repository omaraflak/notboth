A small stack-based language — push, pop, add, compare, call, return — and a
translator from it into your assembly.

Skipping this layer is a common way for the project to stall. Compiling a
high-level language directly to machine code means every language feature has
to be solved in the same breath as every hardware detail, and the two problems
tangle. This layer cuts the knot: the compiler above it only has to think
about meaning, and this translator only has to think about your CPU. Each half
becomes something you can hold in your head.

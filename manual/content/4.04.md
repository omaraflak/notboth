num: 4.04
title: Jumps
sig: Jump(zr, ng, j1, j2, j3) → load
needs: 4.02
---

This gate is just to declutter the CPU implementation. It decides whether the program counter `PC` should load instead of increment.

This decision is based on the ALU's two status outputs and the three gated jump bits from [4.02](/manual.html#s402):

- If `j3` is set, then we should load `PC` if `ng` is set.
- If `j2` is set, then we should load `PC` if `zr` is set.
- If `j1` is set, then we should load `PC` if neither `zr` nor `ng` are set.

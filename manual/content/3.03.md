---
num: 3.03
title: The gated latch
sig: DLatch(d, enable) → q
needs: 3.02
---

One data input instead of two, plus an enable. The contradictory-input problem
of 3.02 is gone by construction: there is no longer any way to ask for one and
zero at the same time.

- **d** — the value to store.
- **enable** — while it is high the output follows `d`; when it drops,
  whatever was there is held.
- **q** — the stored bit.

```wave
!Timing diagram for the gated latch
d        0011011001110011
enable   0011110000011000
>q       0011011111110000
~2-5 transparent — q copies d
~6-10 holds
~11-12 transparent
~13-15 holds
```

One problem remains, and it is fatal: while enable is high this thing is
*transparent*, and changes flow straight through. Chain two, enable both, and
a value races down the whole chain in one go instead of moving one step. A
machine built from these has no notion of “one step at a time”.

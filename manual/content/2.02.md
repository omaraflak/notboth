---
num: 2.02
title: FullAdder
sig: FullAdder(a, b, c) → sum, carry
needs: 1.03, 2.01
---

A gate that adds *three* bits. This will be useful when we extend the adder over the entire 16-bit space, as we will need to sum two digits plus a carry from the previous sum.

::: answer
```circuit FullAdder
in  a
in  b
in  c
out sum
out carry

halfAdder1 : HalfAdder(a = a, b = b)
halfAdder2 : HalfAdder(a = c, b = halfAdder1.sum)
or1 : Or(a = halfAdder2.carry, b = halfAdder1.carry)

sum = halfAdder2.sum
carry = or1.out
```
:::

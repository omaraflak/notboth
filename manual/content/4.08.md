Three boxes and the wires between them: a ROM holding the program, the CPU,
and the RAM. The counter’s output addresses the ROM; the ROM’s output is the
instruction; the CPU’s memory outputs go to the RAM and back.

Keeping instructions and data in separate memories is a real architectural
choice, called Harvard, and what it buys you is simplicity: the machine can
fetch an instruction and touch data in the same tick without them queuing for
the same memory. The cost is that a program cannot modify itself, which is
rarely a loss at this scale.

Wire it up. Then stop, because you have built a computer, and there is nothing
left to add to the hardware. Everything after this is software.
